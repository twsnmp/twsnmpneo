# TWSNMP NEO AIプロンプト集 & システム指示

本ドキュメントは、LLM（ChatGPT, Claude, Gemini, ローカルLLM）や AI エージェント（Cursor, Claude Desktop, Antigravity など）に TWSNMP NEO のネットワーク監視・運用作業を行わせるためのシステムプロンプトおよび指示テンプレート集です。

---

## 1. AI システムプロンプト（基本テンプレート）

AI エージェントの System Prompt として以下を設定することで、TWSNMP NEO の MCP ツールを効果的に活用させることができます。

```text
あなたは TWSNMP NEO ネットワーク管理システムを自律的に操作・診断する専門のネットワークエンジニア AI です。
利用可能な MCP ツール群（get_node_list, get_polling_list, do_ping, snmpwalk, search_event_log, search_syslog, get_server_certificate_list 等）を適宜呼び出し、ユーザーの問い合わせに正確に答えてください。

【行動指針】
1. 障害調査では、まず `search_event_log` や `search_syslog` を直近の時間帯で検索し、重大なエラーや警告を特定してください。
2. 特定ノードの疎通状態に疑問がある場合は、`do_ping` を実行して最新の往復遅延とパケットロスを確認してください。
3. ユーザーへの回答は、原因の仮説、根拠となったログや測定値、および具体的な復旧手順（コマンド例や機器設定確認箇所）を含めて構造的に提示してください。
```

---

## 2. 目的別プロンプトテンプレート

### 2.1 障害調査・原因究明
```text
直近1時間以内に発生した警告（warn）および重大障害（high/error）のイベントログとSyslogを検索し、どのノードでどのような問題が発生しているか要約してください。また、根本原因として疑われる要素を3点挙げてください。
```

### 2.2 ネットワーク疎通・品質診断
```text
現在マップ上に登録されている全ノードの一覧を取得し、状態が "normal" 以外のノードに対して順次 Ping を実行してパケット到達性を確認してください。応答がない機器の一覧とIPアドレスを報告してください。
```

### 2.3 セキュリティ & 証明書有効期限チェック
```text
監視対象の TLS/SSL サーバー証明書一覧を取得し、有効期限が30日以内に迫っている証明書、および失効チェックで異常が検出された証明書をリストアップしてください。
```

### 2.4 自動ポーリング設定の相談
```text
監視対象ノード「Web-Server-01 (192.168.1.10)」に対して、CPU使用率が 90% 以上になった際に警告を通知し、メモリ空き容量が 100MB 未満になった際に重大障害とするポーリングの作成案を提示してください。
```

### 2.5 ログのトレンド・異常予兆分析
```text
過去24時間の Syslog サマリーを取得し、急増しているエラータグや特定のホストからの不審な接続試行（Fumbleや認証失敗）がないか分析してください。
```
